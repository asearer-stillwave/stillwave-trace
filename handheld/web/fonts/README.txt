Stillwave Trace UI fonts (bundled; no CDN, works offline).
Both are SIL Open Font License 1.1: free to use, embed and redistribute commercially (including in a sold product),
as long as the font files are not sold on their own and the license text ships with them (OFL-*.txt here).
Files here are Latin subsets (woff2) made with fontTools from the Google Fonts releases; per the OFL, a modified font
may not use a Reserved Font Name, and neither font declares one.
  anton-latin.woff2          Anton (headlines)                      Copyright 2020 The Anton Project Authors
  jetbrainsmono-latin.woff2  JetBrains Mono (labels, buttons, wght 400-700)  Copyright 2020 The JetBrains Mono Project Authors
Body text uses the system Helvetica / Arial (Liberation Sans or Arimo on the Pi), so no body font is bundled.
