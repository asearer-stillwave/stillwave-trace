Label a dongle

One-time setup for two dongles. Plug in only the dongle you want to label, pick its job, then unplug and replug it (or reboot). Do the same for the other one. Labels live in the dongle itself, so any USB port works afterwards.

Over SSH

sudo sdr-dongles list · sudo sdr-dongles label adsb · sudo sdr-dongles label radio · sudo sdr-mode status
